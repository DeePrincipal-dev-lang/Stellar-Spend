ERROR RESPONSE SCHEMA
================================================================================

Standard Response Format:
{
  "error": string,           // Machine-readable error code
  "message": string,         // Human-readable message (optional)
  "details": object          // Debug info (optional, dev-only)
}

Error Types (8 total):
  - validation_error (400)   - Invalid input or constraints
  - unauthorized (401)       - Missing/invalid authentication
  - forbidden (403)          - Valid auth but insufficient permissions
  - not_found (404)          - Resource does not exist
  - conflict (409)           - Duplicate or invalid state
  - rate_limit_exceeded (429) - Rate limit threshold exceeded
  - external_service_error (502) - Upstream service unavailable
  - server_error (500)       - Internal server error
